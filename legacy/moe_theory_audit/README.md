# MoE 有限步路由事件：数学核对包

本包用于审查研究设想，不是已经完成的量化方法或预训练模型实验。

## 文件

- `verify_math.py`：可复现的 CPU 数学与随机小网络核对。
- `results.json`：本次实际运行保存的完整结果，包括没有改善候选选择的对照。
- `environment.json`：生成本次结果的运行环境版本。

## 运行

需要 Python、NumPy、SciPy、PyTorch。无需 GPU、网络、模型权重或数据下载。

```bash
python -m pip install numpy scipy torch
python verify_math.py
```

脚本使用 float64 和固定随机种子，运行后会覆盖同目录的 `results.json`。
不同依赖版本可能导致最后几位数值不同。

## 检验对象

1. 有限经验损失的导数与连续总体风险的导数不是同一个对象。
2. 无偏置线性 router + RMSNorm 的 Top-k 集合可由归一化前的线性分数精确决定。
3. 居中 router 的零空间可以保持选中集合，但不保证 gate 权重或模型功能不变。
4. 有限步损失变化 = 固定旧路由的平滑变化 + 新输入处带符号的路由事件校正。
5. 在固定、合法的量化舍入候选集合中，对比二阶近似、事件校正近似与穷举真实损失。

## 实验限制（必须与结果一起阅读）

所有网络均为随机初始化的小网络，不是 OLMoE 或其他预训练模型。
专家使用简单的 SiLU 前馈网络，toy MoE 对选中 Top-k 权重重新归一化。
OLMoE-1B-7B-0924 的官方配置为 norm_topk_prob=false；实际模型实验必须保留其真实聚合方式，不能直接把本 toy 的数值结果当作 OLMoE 结果。
有限步恒等式及相应分析不要求这两种归一化方式相同。

枚举舍入实验：每个随机种子选择 8 个最接近舍入中点的权重坐标，枚举 256 个合法 floor/ceil 组合。候选坐标只由舍入距离选择，没有根据试验结果筛选。
其余网络权重固定；这里只模拟一个输入投影的 3-bit 权重格点，实际运算使用 float64。
评分和候选真实误差使用同一批输入，没有留出集泛化结论。

校正项使用精确的候选终点反事实分支输出；小维度 Hessian 也精确计算。
为便于检查，脚本密集计算所有专家，没有实现只对事件 token 稀疏重算。
因此，本包没有验证大模型收益、4090 峰值显存、校准速度、部署速度或完整算法的新颖性。

另一组随机候选实验中，校正改善了数值预测，但未改善最优候选选择。
它保留在 results.json 中，用来说明“相关性更高”不等于“得到更好的量化模型”。

## 正确解读

可以据此检查恒等式、反例、条件以及一个受控候选选择现象。
不能据此宣布方法优于现有 MoE PTQ 方法，更不能宣布已经达到主会投稿要求。
